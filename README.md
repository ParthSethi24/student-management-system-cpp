# Student Management System

This is my C++ project for managing student records.

## Features
- Add student details
- Show all students
- Search student by ID
- Update student details
- Delete a student record
- Save records in a text file

## Concepts used
I used structures, arrays, functions, loops, switch case and basic file handling.

## How to run
Open this folder in VS Code and open the terminal.

Compile:
```bash
g++ main.cpp -o StudentManagementSystem.exe
```

Run on Windows:
```powershell
.\StudentManagementSystem.exe
```

The program stores the records in `students.txt`, so they are available when the program is opened again.
